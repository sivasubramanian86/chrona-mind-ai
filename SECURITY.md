# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please report it privately:

1.  **Do not create a public GitHub issue.**
2.  Email us at security@chronamind.ai with a description of the issue.
3.  We will respond within 48 hours.

## Secrets and API Keys
- No API keys should be committed to this repository.
- Use environment variables or secure storage mechanisms.
- All local user data is encrypted at rest using industry-standard AES encryption.
